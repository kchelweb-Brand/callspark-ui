# Kchel Dialer brand assets

Generated by `npm run brand` (`scripts/export-brand-assets.mjs`). The geometry
comes from `src/components/brand/Logo.tsx` and the colours from the oklch
tokens in `src/styles.css`, so re-running it after a brand change reproduces
the whole set rather than leaving these to drift.

## Colours

| Token | Hex | Used for |
| --- | --- | --- |
| Green | `#0ea053` | The stem of the K |
| Blue | `#0076d3` | First chevron |
| Yellow | `#f0c630` | Second chevron |
| Black | `#090e12` | Tiles, wordmark on light backgrounds |

## Which file to use

**PNG keeps its transparent background. JPEG never can** — every `.jpg` here is
flattened onto white or onto brand black, so pick the one that matches what
it's going on. Use JPEG only where PNG isn't accepted (some invoice tools, some
print shops, older CRMs).

### App icon — square, rounded tile

For anything that wants a square: app stores, a Google/Meta business profile,
WhatsApp Business, a Slack app, a favicon source.

- `kchel-icon-dark.png` · 1024 — the primary icon
- `kchel-icon-dark-512.png`, `kchel-icon-dark-256.png` — same, smaller
- `kchel-icon-light.png` · 1024 — white tile, for dark UIs and dark letterheads
- `kchel-icon-dark.jpg`, `kchel-icon-light.jpg` — where PNG isn't accepted

### Mark alone — no tile

For watermarks, loading spinners, a bullet next to a heading.

- `kchel-mark-color.png` · 1024 (and `-512`)
- `kchel-mark-white.png` — for photos and dark panels
- `kchel-mark-black.png` — for light panels
- `kchel-mark-color-on-white.jpg`

### Horizontal lockup — mark + wordmark

The default logo. Website headers, email signatures, invoices, slide masters.

- `kchel-logo-horizontal.png` · 1546×448 — dark wordmark, transparent
- `kchel-logo-horizontal-800.png` — same at 800px wide, for email and web
- `kchel-logo-horizontal-white.png` (and `-800`) — white wordmark, for dark backgrounds
- `kchel-logo-horizontal-on-white.jpg`, `kchel-logo-horizontal-on-ink.jpg`

### Stacked lockup

Where the space is tall rather than wide: a business card, a poster, a
square ad, a hold-screen.

- `kchel-logo-stacked.png`, `kchel-logo-stacked-white.png`
- `kchel-logo-stacked-on-white.jpg`, `kchel-logo-stacked-on-ink.jpg`

### Single colour

For anything that can't print colour — a rubber stamp, an engraved plate, a
fax header, an embroidered shirt.

- `kchel-logo-mono-black.png`
- `kchel-logo-mono-white.png`

### Social / link preview

1200×630, the size Facebook, LinkedIn, X and Slack all crop from.

- `kchel-social-1200x630.png` / `.jpg`

## Using it well

- Leave clear space around the logo of at least the height of the green stem.
- Don't recolour it, stretch it, add a shadow, or put the colour version on a
  busy photo — use `kchel-logo-horizontal-white.png` there instead.
- Below about 24px tall the two chevrons merge. Use the app icon at those
  sizes; `scripts/generate-icons.mjs` drops the second chevron for favicons
  for exactly this reason.
